### Key Techniques (from reference)
- **Sine table**: 256-byte page-aligned signed cosine table; sin(i) = cos_table[(i+64)&255]
- **Multiply**: 8x8 shift-and-add (196-204 T-states), signed via sign-correct wrapper
- **Rotation**: Sequential Z then Y then X; 4 muls + 2 adds per axis
- **Projection**: Parallel (add center offset) or perspective (divide by Z+dist)
- **Line draw**: Bresenham with incremental screen pointer; SET bit,(HL) per pixel

### Cosine Table (256 bytes, precomputed)
`cos_table[i] = round(127 * cos(i * 2*pi / 256))`
sin is offset: `sin_table[i] = cos_table[(i+64) & 0xFF]`

Key values: i=0→127, i=64→0, i=128→-127, i=192→0

### pasmo v0.5.4 Gotchas (IMPORTANT)
- No `: ` statement separator — must have one instruction per line
- No `ALIGN n` — use `DS (256 - ($ MOD 256)) MOD 256` instead
- Only `LD (nn), A` is valid for 8-bit absolute stores; NOT `LD (nn), B/C/D/E/H/L`
  → go via A: `LD A, H` then `LD (label), A`
- `DJNZ` is ±127 bytes max — large loops need `DEC B : JP NZ, label`
- Multiple labels per line not supported — one `label: DEFB n` per line
- `HIGH label` operator works correctly for page-aligned addresses
